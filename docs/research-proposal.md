# 定稿研究方案

## 范式与目标

在线学习型组合优化：在订单动态到达、未来不可见、加工不可抢占的柔性流水车间，通过联合订单选择、机器分配与派工时机，提高按时完成整个订单的比例。

## 两项设计

1. HGNN基础策略上的动作条件交付竞争图残差：工艺/交付与产能竞争两路径处理可知资源承诺的局部变化。零初始化修正层及门控保持示范初始化起点。
2. 共享未来、固定教师/冻结策略后续下的可靠性加权成对策略改进。有限窗口未来生成后将比较订单处理至全部解决；失败分支不产生标签。在线不搜索。

规则示范、PPO、等待和并行属于支持技术。固定教师SPT；不依据测试实例更换教师。观察与动作接口保持公开信息隔离。固定测试每参数一例，性能主张以正式记录为准，保留失利范围。
